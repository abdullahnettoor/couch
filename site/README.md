# couch-site

The landing page for [Couch](https://github.com/abdullahnettoor/couch), planned for `couch.abdullahnettoor.com`. A static site: plain HTML, CSS and TypeScript built with Vite. No framework, no tracking, no cookies, no third-party requests (Geist and Geist Mono are self-hosted, SIL OFL).

## Run it

```sh
pnpm install
pnpm dev          # http://localhost:5173
pnpm build        # type-check, then build to dist/
pnpm preview      # serve dist/ at http://localhost:4173
```

## Settings in one place

`src/config.ts` holds `GUMROAD_URL` (a **placeholder** until the Gumroad product exists), `GITHUB_URL`, `RELEASES_URL` and `SITE_URL`. They are filled into `index.html` at build time (`{{GUMROAD_URL}}` and so on), so every link works without JavaScript.

## Screenshot slots

Every product picture is a **slot**: an element marked `data-slot="<name>"` inside a TV or phone frame. To replace one after the real shoot, drop a file named `src/shots/slot-<name>.png` (or `.jpg`, `.webp`) and rebuild. It replaces whatever the slot holds (a CSS mock or the interim picture); no code change. Frames are 16:9 for the Screen and about 9:19 for the Remote; crop the shot to match (for example 1920×1080 and 1080×2280), and keep each under about 150 KB.

| Slot name | Where | Today | Wanted |
| --- | --- | --- | --- |
| `hero-screen` | Hero TV | CSS mock of Home | Home, with the Apps row |
| `hero-remote` | Hero phone | CSS mock of the Remote | The Remote (D-pad) |
| `remote-screen` | "Your phone is the remote" TV | CSS mock of Home (animated focus) | Home |
| `remote-phone` | Same section, phone | CSS mock of the Remote (animated presses) | The Remote |
| `apps-screen` | "The Apps you already use" TV | CSS mock of the App tiles (names only) | Apps row; YouTube shots should be the guest view. Never a signed-in Netflix page |
| `library-screen` | "Your Library" TV | `src/shots/library.jpg` | A full Library shelf |
| `privacy-screen` | "Nothing leaves your Mac" TV | `src/shots/settings.jpg` | Settings |

The "Ready in two minutes" cards use `src/shots/remotes.jpg` (step 2) and `src/shots/player.jpg` (step 3) directly; swap those files in place, keeping the names, or edit `index.html`. The four JPEGs are copies of `docs/screenshots/` in the Couch repo. A replaced slot loses its mock animation (the animation only runs on the CSS mocks), which is expected.

Other assets: `public/icon.png`, `favicon.png` and `apple-touch-icon.png` come from `build/icon.png` in the Couch repo. `public/og.png` (the social card) is generated by `node scripts/og.mjs` from `scripts/og.html`; edit that file and rerun to change it.

## Checks

`node scripts/shoot.mjs <dir>` writes full-page and viewport screenshots at 1440, 1280, 1024, 768 and 390 px from `pnpm preview` (needs Google Chrome). Lighthouse on the local build: performance, accessibility, best practices and SEO all score 100 (mobile and desktop).

## Deploy (not done yet)

`wrangler.jsonc` serves `dist/` with Workers static assets on the custom domain `couch.abdullahnettoor.com`. `pnpm deploy` builds and runs `wrangler deploy`, which creates the subdomain and its certificate. Do not run it until the Gumroad URL is real and the screenshots are in.
